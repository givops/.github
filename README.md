# GivOps GitHub Organization Profile

This repository contains the public organization profile rendered on the [GivOps GitHub organization page](https://github.com/givops).

## Contents

- [`profile/README.md`](profile/README.md) — Public GitHub organization homepage (overview, architecture diagram, public repositories, previews, and pilot contact).
- [`profile/assets/`](profile/assets/) — Brand banner and product preview images rendered on the organization profile.
- [`scripts/verify-local.sh`](scripts/verify-local.sh) — Local validation script for links, asset integrity, Mermaid syntax, public-boundary hygiene, and whitespace checks.

## Local Verification

Run all checks locally from the repository root:

```sh
bash scripts/verify-local.sh
```

For full platform details, open architecture documentation, and pilot inquiries, visit [givops.io](https://givops.io/).
